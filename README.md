# Welcue – AI Powered Student Placement Assistant

Welcue is a frontend-based academic project designed to assist students in placement preparation through profile analysis, AI-driven career recommendations, and interactive quizzes.

The system focuses on improving student readiness by providing personalized guidance and a clean, user-friendly interface.

---

##  Features

-  Student Profile Creation  
-  AI Career Recommendations  
-  Quiz Module with Difficulty Levels  
-  Interactive Dashboard UI  
-  Responsive & Modern Design  

---

##  Technologies Used

- HTML  
- CSS  
- JavaScript  

---

##  How to Run the Project

1. Download or clone the repository  
2. Open `index.html` in any modern web browser  

No additional setup or dependencies required.

---

##  Project Objective

This project was developed as part of an academic exercise to demonstrate:

- Frontend development skills  
- UI/UX design principles  
- Logic structuring for AI-driven features  
- Real-world placement assistance concepts
